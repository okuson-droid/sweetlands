# decisions.md 追補 §11：不具合・UI 不良の改修（2026-10-12）

準拠：`SweetLands_rules.md`（v1.0）と `SweetLands_rules_v1.1.md`（v1.1）。ルールの変更はない（11.4 の時計塔駒の条件は、実物のキャラボードに合わせたデータの訂正である）。

## 11.1 手札のドラフト（§10.2）の同時選択

- 以前は、同じ巡のピックを手番順に1人ずつ選ばせていた。実物では全員が同時に選ぶため、同じ巡では全員が同時に選べるようにした。
- `Pending.waiting`（省略可）を追加した。同時に選べる席の一覧であり、このとき `options` は全員分の選択肢を合わせたもの、各選択肢の `data.player` が選ぶ席を表す。`player` は `waiting` の先頭（ホットシートではこの順に回答する）。
- 選択肢 ID は以前と同じ `card:<カード ID>` のままにした。カード ID は束をまたいで重複しないため、ID だけで選んだ席が決まる。乱数は消費しない。このため、以前の記録（手番順に選んだ手の列）はそのまま再生でき、同じ局面になる（旧エンジンで作った記録5局を新エンジンで再生し、全プレイヤーの状態とログが一致することを確かめた）。
- 同じ巡のピックは互いに独立なので、選ぶ順番に依らず同じ結果になる（`tests/rules.test.ts` で確かめる）。
- `viewFor(state, seat)`（engine.ts）：席から見た局面を返す。`waiting` があるとき、その席の選択肢だけに絞り、`player` をその席にする。画面（`Game.tsx`）とオンラインの操作権の判定（`useOnlineGame.ts`）はこれを通して見る。
- オンライン：同時選択の手は、ほかの人の手と書き込みが重なりうる。`room.transact` で読み直した手の列にその手がまだ合法なら末尾に足し、合法でなければ送らない。ほかの手は従来どおり `write` で送る。
- ドラフトで取ったカードはドラフトの終わりまで手札に入らないため、候補の小窓に「取ったカード」として自分の分だけを出す。選び終えた人には、ほかの人を待っている旨を出す。
- `e2e/online.mjs` に4つ目の引数（ロビーで入れるヴァリアント）を足した。同時選択の局面では操作できる人が複数いてよいとし、そのうちの1人をランダムに動かす。

## 11.2 最終得点の表

- `finalScores` の内訳は、条件つきの行（テント駒5個・家駒5個・ビル駒5個のボーナス）を条件を満たす人にだけ入れていた。表は1人目の行の並びを見出しにして、行番号で全員の値を並べるため、条件を満たす人がいると以降の行がずれた（合計と順位は各人の内訳の和なので正しかった）。
- 条件を満たさない人にも 0 点の行として必ず入れ、全員の行の並びと見出しをそろえた。港の行の見出しから個数を除いた（人によって見出しが変わるため）。

## 11.3 準備の画面

- キャラクター・地図ボードの選択（準備のドラフトを含む）の小窓に、この卓のマイルストーン・最終得点計算・上級スキルタイルを文で読める形で開いて見られる欄を足した（`PublicTiles`）。小窓が盤面を覆うため、以前は確認できなかった。
- 地図ボードの選択で、面ごとに地図そのもの（`MapBoard`）を出し、その下に選ぶボタンを並べた。A面は5枚とも同じ地図なので1つにまとめ、どのボードの A面かのボタンを並べる。`mapPreview`（engine.ts）は状態を変えずに仮のプレイヤーを作る。

## 11.4 時計塔駒の配置条件

- 建物駒の条件のうち「家駒」としていたもの（アリス・ロータス・エルサ・サクラ・カルメン・セナ・コーラル・ジャスミン）は、実物では任意の建物駒である（ユーザー確認 2026-10-12）。`ClockReq` の `bld` で `type` を省略したとき任意の建物駒とし、上記8人をそれに改めた。テント駒・研究所駒・ビル駒の指定はそのままである。
- 条件が緩む方向の訂正であり、以前の記録の手はすべて合法のまま再生できる。

## 11.5 盤面の操作

- 効果の解決の順番の選択：横長レイアウトでは帯が画面の上部にあるが、効果の一覧は帯の上に開いていたため、画面の外へはみ出して選択肢が見切れた。横長レイアウトでは帯の下に開くようにした。
- オートメーション化の申し出：プレイしたカードの一覧を自動で開いていたが、一覧が個人ボードの産業列（置き先）にかぶさり、置けないことがあった。プレイしたばかりのカードは1枚だけなので、置き先の列をクリックしても選べるようにし（`gestures.ts`）、一覧は自動では開かず●印だけを出すようにした。
- ドラッグの置き先は、ポインタ位置で重なった要素を上から順に見て、置ける置き先を拾うようにした（`findDest`）。展開した一覧の下にある置き先にも落とせる。持ち上げているあいだ、そのカードを収めた一覧は薄く表示する。
