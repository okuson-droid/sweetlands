# decisions.md 追補 §12：不具合・UI 不良の改修 その2（2026-10-12）

準拠：`SweetLands_rules.md`（v1.0）と `SweetLands_rules_v1.1.md`（v1.1）。ルールの変更はない（12.6 はデータの訂正である）。

## 12.1 準備中にロビーへ戻れない

- キャラクター・地図ボードの選択の小窓（`.modal-back.setup`）が上の帯まで覆い、「ロビー」ボタンが押せなかった。このため、選択の途中で誰かが抜けると、ロビーへ戻ってゲームを終了する操作ができなかった。
- 準備の小窓の背景を上の帯の下から始め、帯を小窓より手前に出した（`styles.css`）。
- 残る制約：オンラインのゲームを終了して消せるのは作った人だけである（Supabase の行の削除権限による）。作った人が抜けたままになると、ほかの人は終了できない。

## 12.2 コピーアクション（特殊アクションL など）をクリックで行えない

- ディスクをクリックで持ち上げてからコピーするエリアをクリックすると、コピー先を選ぶ段階に入らず、持ち上げが解けていた（`useTarget` の onClick が、手の ID が空の置き先を「下ろす」として扱っていた）。
- アクションエリアへの空の置き先をクリックしたときは、ドラッグと同じくコピー先を選ぶ段階に入るようにした（`startCopy`）。

## 12.3 クッキーラビット駒の置き場のボーナス表記が消える

- 置き場に印刷されたボーナスを、駒が残っている置き場（次に取る駒を除く）にだけ描いていた。次に取る駒と取り終えた置き場では表記が消えていた。
- 常に表記を描き、取り終えた置き場では薄く表示する。

## 12.4 手札を使うフリーアクションの操作順

- 以前は手札のカードをフリーアクションのマスへドラッグしていた（カードの支払いを先回りで答える）。ユーザーの指示により、先にフリーアクションのマス（サクラ・モチは能力）をクリックし、そのあとの支払い（`payHand`）で手札のカードを選ぶ順に改めた。
- `payHand` では、手札のカードをクリックしても選べる（捨て札置き場へのドラッグも残す）。
- fa7 のマスは、ディスクのドラッグ（fa7d）とクリック（fa7h：手札で払う）の両方を受ける。
- 合法手・選択肢 ID は変えていない。

## 12.5 拡大表示（キャラクター名など）がすぐ消える

- 拡大表示の位置を、幅を 300px と見積もって決めていたが、実際の幅は最大 348px（max-width 320px＋padding＋枠）ある。画面の右寄りでは拡大表示がポインタの上に重なり、要素から外れた扱いになって表示と消去を繰り返していた。
- 見積もりを実際の上限の 348px にした（`zoomPos`）。

## 12.6 キャラボード η のオートメーション時能力

- コーラル・ライラとジャスミン・メイのボード（η）の林業（緑）の列の印刷された能力は、1工業点ではなく1都市点である（ユーザーの報告 2026-10-12）。`PRINTED_AUTO.η.for` と `characters.json` を訂正した。
- 選択肢 ID と乱数の消費は変わらないが、進行中のゲームでこの列をオートメーション化していれば、再生した局面の得点（工業点と都市点）が以前と変わる。その後の選択肢が得点に左右される場面があれば、記録の手が合法でなくなりうる。
