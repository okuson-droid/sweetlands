# decisions.md 追補 §14：スマートフォンのレイアウト（2026-10-13）

設計は `ui_design_22_mobile_layout.md`（UI設計書 追補 §22）。ここには実装上の判断を記録する。ルールとゲーム処理（`src/game/`）は変更していない。選択肢 ID と乱数の消費も変えていない。

## 14.1 構成

- `src/ui/MobileLayout.tsx` を新設し、縦持ちの `PortraitLayout`（案A）と横持ちの `LandscapeLayout`（案D）を置いた。旧来の狭い画面用 `NarrowLayout`（左端の縦タブ）は削除した。
- レイアウトの選択は `useLayoutMode()`（`MobileLayout.tsx`）：幅 1280px 以上かつ高さ 600px 以上なら横長、それ以外は高さ＞幅で縦持ち、そうでなければ横持ち。`resize` と `orientationchange` で切り替える。
- 横長と共有する部品（上の札 `TopBar`・相手の帯 `Opponents`・設定 `SettingsPanel`・ログ `LogPanel`・`LayoutProps` など）は `Game.tsx` から `src/ui/GameParts.tsx` へ移した。`Game.tsx` と `MobileLayout.tsx` の相互 import を避けるためである。
- 狭い画面用の `HandBar`（手札・サプライの横帯）は使う所がなくなったため削除した。
- スタイルは `src/ui/mobile.css` に集めた（`.game.mobile.portrait` / `.game.mobile.landscape` の下）。`styles.css` と `layout.css` の旧来の狭い画面の規則（`.game.narrow`・`.vtabs`・`.portrait-guard`）は削除した。

## 14.2 判断

- 合法手のキー → 面（共通・街・キャラ・工業・手元）の対応を `paneOf` に集めた。光っている対象（持ち上げ中は置き先、そうでなければ出発点と直接触る対象）の面にタブの●を付け、対象がいまの面になければ切り替える。判定は合法手（`aff.clicks`・`aff.drags` のキー）だけから導く（設計原則3）。
- 横持ちでは地図が常に見えているため、右パネルは地図以外の対象だけを追う。手札のタブは、カードが対象のときだけ追う（手番の最初はカードも対象だが、共通の面を先に出す）。
- 縦持ちの手元のシートを自動で開くのは、対象がすべて手元にあり手札のカードを含む場面と、持ち上げたものの置き先が手札の枠（`hand`・`keep`）のときだけにした。捨て札置き場は畳んだシートにも出ているので、それが置き先のときは開かない。開くとシートの背が伸び、指の下の要素がずれるためでもある。
- タップのあとのクリックを捨てる（`interaction.tsx` の `swallowNextClick`）。持ち上げや手の送信で面やシートが切り替わると、遅れて届くクリックが別の要素に当たる。縦持ちの自動対戦で、ダイヤを持ち上げた直後にシートが開いてクリックが別の要素に当たり、持ち上げが解けて進まなくなる不具合として見つかった。置き先のヘクスに当たれば意図しない手になりうるため、所作の経路で防いだ。待ち時間は `constants.ts` の `CLICK_SWALLOW_MS`（500ms）。
- 盤面の縮小は `Fit`（`MobileLayout.tsx`）で、CSS の `zoom` を使う。横長レイアウトがすでに `zoom` を使っており、縮めても `elementsFromPoint` による置き先の判定とクリックがそのまま効くため。キャラボードと工業ボードは本来の幅（max-content）を測って縮め、共通の盤面は幅 360px を基準に組んで足りないぶんだけ縮める。
- 地図の2本指の拡大縮小は `MapBoard` の Pointer Events で扱う（指ごとの位置を持ち、2本になったらつまみ始めの距離と表示範囲を覚える）。ホイールの拡大縮小と同じ範囲（幅 6〜24）に収める。「＋」「−」「全体」のボタンは `@media (pointer: coarse)` のときだけ出す。
- 共通サプライのアクションディスクの山は、`SharedSupply` の `hideIdleDisc` で、持ち上げられるときだけ出す（スマートフォンのみ）。横長レイアウトは従来どおり常に出す。
- 帯（`Band`）に `compact` を足した：解決中／次の一覧を帯の中の札に畳み、持ち上げ中の札と「戻す」ボタンを出す。持ち上げているものの名前は `heldLabel`（`Band.tsx`）が出発点のキーから作る（表示用であり、判定には使わない）。
- 準備のドラフトの小窓は、横長では候補の欄（`.draft-body`）だけをスクロールする。背の低い横持ちではその欄の高さが0に潰れて候補を選べなかったため、スマートフォンでは小窓全体をスクロールするようにした。
- `index.html` の viewport に `viewport-fit=cover` を足し、ホーム画面に追加したときの全画面表示（`apple-mobile-web-app-capable` など）を宣言した。

## 14.3 受け入れ検査（`e2e/autoplay.mjs`）

- 第1引数に `portrait`（390×844）と `landscape`（844×390）を足した。`touch` は `landscape` と同じ大きさにした（旧来の 800×360 は廃止）。タッチの自動プレイヤーは、持ち上げたあとに置き先が見えなければ、●印のタブ（`.mtabs`・`.mside-tabs`）か手元のシートの見出しを押す。
