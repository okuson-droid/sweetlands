# decisions.md 追補 §16：ヴァリアント「キャラクターの上方修正」（2026-10-14）

準拠：`SweetLands_rules.md`（v1.0）と `SweetLands_rules_v1.1.md`（v1.1）。上方修正の中身は持ち主の指示による（2026-10-14）。ヴァリアントを採用しない限り、ルールと判定は変わらない。

## 16.1 上方修正の中身

ヴァリアントを採用すると、次のキャラクターが全員の卓で修正版になる。

| 対象 | 通常 | 上方修正版 |
|---|---|---|
| ナタ・パステル／ビスキュイ・バステト（ボードγ）の鉱業列（灰色）の印刷オートメーション | ゴールドの収入値を2上げる | 道駒を1個置く |
| ナタ・パステル：工業トラックの工業点アイコン（パス時） | 1／1／2／2 | 1／2／3／4 |
| ビスキュイ・バステト：基本能力（フリーアクション、ラウンド1回） | 研究所駒がある自分の都市1つにつき工業トラック1歩 | 自分の研究所駒1個につき工業トラック1歩 |
| ソルビー・ショコラ／リッカ・ベリー（ボードε）の農業列（黄色）の印刷オートメーション | ゴールドの収入値を4上げる | 地形タイルを1枚置く（種類は任意。α・βの農業列と同じ） |
| リッカ・ベリー：基本能力（「クッキーラビット駒を置く」アクションエリア C・O のコスト） | 麦を好きな個数だけ木材で払える | 麦を好きな個数だけゴールドで払える（麦1個につき1ゴールド） |
| コーラル・ライラ／ジャスミン・メイ（ボードη）の林業列（緑）の印刷オートメーション | 1都市点 | 道駒を1個置く |

持ち主に確認して決めた点：

- 灰色は鉱業列、黄色は農業列、緑は林業列である。
- ナタの 1／2／3／4 は、馬車駒・機関車駒の両方のマーカーに効く。
- ナタの時計塔能力（今回のパスで得る1工業点につき1勝利点）は、増えた工業点にそのまま連動する。
- ビスキュイの時計塔能力（研究所駒が1個以上ある自分の都市1つにつき1工業点）は変えない。
- リッカの代わりの支払いは、木材をゴールドに置き換える（木材では払えなくなる）。

## 16.2 実装

- `GameConfig.variants.charBuff`（省略可。未定義は不採用）。キャラクターごとの判定は `characters.ts` の `isBuffed(config, name)` に集めた。
- 印刷オートメーション：`boards.ts` の `printedAuto(board, row, buff)`。差し替えは `PRINTED_AUTO_BUFF` に持つ。
- 工業点アイコン：`queries.ts` の `passedIp(p, buff)`。ナタのときだけ `IP_VALUES_NATA_BUFF` の値で数える。時計塔の条件「工業点アイコン」（コーラル・ジャスミン）にも同じ関数を使うが、値が変わるのはナタだけである。
- ビスキュイ：歩数は `biscuitSteps`。上方修正では研究所駒の数を数える。研究所駒は都市（3種類以上の建物駒の集まり）に属していなくてもよい。使えるのは、歩数が1以上のとき（研究所駒が1個以上あるとき）である。
- リッカ：`rikkaSub` が代わりに払う資源（通常は木材、上方修正ではゴールド）を返す。選択肢 ID は以前と同じ `split:個数` で、data は `{ wood | gold: 個数, wheat }` とした。コピー（特殊アクション L など）の4ゴールドを払った残りで払えるかを判定する。
- 選択肢 ID と乱数の消費は変えていない。ヴァリアントを採用しないゲームの手の列は、以前と同じ結果に再生される。

## 16.3 画面

- ロビーのヴァリアントの欄に「キャラクターの上方修正」を足した。自動対戦の `v=1` は、このヴァリアントも採用する。
- キャラクターの選択、個人ボードのキャラクター名の行、キャラクターの拡大表示に「上方修正」の印と変更点を出す。基本能力の文は `basicTextOf` で修正版に差し替える。
- 個人ボードの産業列の印刷オートメーション、工業トラックの工業点アイコンの値（ナタ）、パス時に得る工業点の表示は、修正版の値を出す。
- リッカの支払いの内訳のボタンは、選択肢の文（「麦1・ゴールド3」など）をそのまま出す。
