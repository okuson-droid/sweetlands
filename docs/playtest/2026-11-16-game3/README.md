## 得点を増やす戦術の提案（重なったもの）

- 手札の枚数が手番の数になる。J・J2・追加ドローエリアを序盤に取り、1スペースのエリアと使いたいエリアの1人目は最初の手で取る（全席が1〜2回先取りされて手札2枚を払った）。
- 他席が右端に迫る繁栄トラックは、スキル1〜3（同色3歩）で先に右端へ着き、右端のボーナスを取る（P2 がラビットで7点）。
- カードの代金なしの建物駒は、列の上限が増える段か高い段に当てる。
- スキル12（産業ボーナス1回3点）・時計塔・パス時の能力は早く取るほど回数が増える。
- 建物駒のエリアの前に、個数×鉄3など代金をそろえる（エリアの効果の途中はフリーアクションを挟めない）。
