## 次の省力化の提案（4局目の15本から、多い順）

- 道駒の辺の選択肢（毎回20〜30行、役に立つのは数行）を「裏返る辺・新しいヘクスに届く辺」だけにし、残りは件数にまとめる（6本）。
- bundle・eff を詰まる番号でなく効果の名前で選べるようにし、効果つきの手番を1回の `move` にする（4本）。
- `show --only self` に「いまの資源を全部麦に換えると何個か（G÷4＋木材・鉄÷3＋余る手札×2）」と、使える手番の数（手札−1）を1行で出す（3本。配分の暗算のやり直しが1ラウンド3〜5回）。
- brief に段の型の例を足す（`fa6 basic:払う basic:得る`、`fa7h card: basic:`、`fa1 basic: card: choice: hex:`）（4本）。
- `wait` を自分の番が来るまで戻らないようにする（1本。ただし道具の上限の約120秒があるため、時間切れは残す必要がある）。
