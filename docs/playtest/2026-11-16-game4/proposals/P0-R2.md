# P0 第2ラウンドの提案
## 1. 得点を増やす戦術
- 列2（カード-3G・建物駒の鉄-1）の回は、フリップ→P（テント・ビル・ビル）→K8→カード3枚の順で、建物駒5個のマイルストーン（10点）と都市1・港2つ（-40→-10）を1ラウンドで取れた。ビル2個で鉱業の上限が2になり、リタ（鉱山1枚）を入れてから 4,14 のibに置くと、タイル1枚で鉱山2枚・工業+1・カード1枚が出た。
- カードの順番で条件を満たす：レディ（ショートケーキ）を先にプレイすると、バロンの「条件に応じて地形タイル1枚」が出た（1G でタイル1枚）。
- 食料は0のまま。P2 はラビットの繁栄を6歩。次は N・バーナードを最初に取り、ラビットは対象の数で取る。
## 2. 省力化
- (1) 無駄：ref の rules・areas・free・board を別々に2回引いた。eff: の段を知らず失敗1回。fa6 の型の下見1回。
- (2) 変更案：①resume に areas・free・自分の board の段を含める。②カードの下見で「先に解決する効果」が出る段は、order:auto を既定にして hex だけ聞く。③パスの列の選択肢に、いまの値での見込み点（港2→6点、カード5→5点）を添える。
- (3) 自分：ラウンドの初めに「ゴールド・木材の総量→プレイするカードと捨て札にするカード」を1回で割り振り、以後は考え直さない。
