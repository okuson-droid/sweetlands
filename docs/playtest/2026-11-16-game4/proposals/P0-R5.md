# P0 第5ラウンドの提案
## 1. 得点を増やす戦術
- 家5個目は終局で都市点×1（12点）＋建物駒2点。林業の産業ボーナス（都市点1）を重ねるほど効く。R5 の E/P の最後の1個は家5に当てる。
- R5 の初手は M（タイル3＋道3）で置き場と緑3歩を作り、次に P。建物駒の右端は14→36点、道の右端は8→17点。右端2本にダイヤ2が要るので、家3（ダイヤ2）を束の先頭で解く。
- 余った手札は J/J2 で2枚に増やし fa1（手札1＋資源3→タイル）に回す。外周の ra・pr のヘクスで1枚4〜5点、外周の枚数も16対13で守れた。
## 2. 省力化
- (1) 無駄：自動で進む段に指定を書いて失敗4回（収入の2歩目、手札コスト、fa1 の内訳、緑の歩）。fa3 の型（pay でなく basic）で失敗1回。計画の勘定を3回やり直した（木材の不足、E を取られた後）。
- (2) 変更案：①move は、自動で解決済みの段に当たる余分な指定を読み飛ばして続ける。②brief に型の例を足す：「fa3 basic:0-3-0」「fa1 basic: card: choice:0 hex:」「fa7h card: basic:」。③resume の点検に「いまパスしたら何点」と「建物駒の次の段と終局の倍率（家5・テント5・ビル5）」を1行で出す。
- (3) 自分：R5 の頭に「資源の総量÷建物1個8」で建物の個数を先に決め、E/P は資源が足りる最初の手番で取る。
