# P1 第1ラウンドの提案
## 1. 得点を増やす戦術
- 自動化したカードもタグが残る。最初に知っていれば無料の2枚をショートケーキ札に当て、マイルストーン 4b を R1 に近づけられた。
- ショップ駒（鉱業）は木材2・鉄3で「鉱山タイル＋G収入+2＋キューブ」。カルメンはテントより先にショップが得（R1 で収入 G14→21、麦0→5、鉄2→5）。
- 1スペースの K8 は2巡目まで残った。A・E を先に取り（2人目は手札2〜3枚）、金は後でよい。
## 2. 省力化
(1) 無駄：ref 全文を読んだが個人ボード欄はキャラクター選択前は空で、選んだ後に読み直した（2回）。eff: の段を知らずに move が1回失敗。首都の建物駒の効果を4回に分けて呼んだ。タグが残るかの下見に1回。
(2) 変更案
- ref --only chars に各キャラクターの個人ボード（印刷されたオートメーション能力と段のボーナス）を並べる。
- brief に「自動化したカードのタグは残る」「パス時の支援の列は空いている列から自由に選ぶ」「ショップ駒は産業ボーナス」を1行ずつ足す。
- 収入値を選ぶ段を `res:wood` 1つで choice:0 を兼ねるようにする（bundle の後の2段を1段に）。
(3) 自分：ref は chars・maps だけ先に読み、残りはキャラクター決定後に1回。効果つきの手は最初から1段ずつ打つ。
