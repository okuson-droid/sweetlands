# P0（エリ・マカロン）第4ラウンドの目標

## 目標
1. 研究所駒を3・4個目まで置き、工業を 13→17 歩にする（機関車駒を出す。通過アイコン 4→6）。灰の繁栄「オートメーション化」を右端（2→5）にする。
2. 地形タイルを6枚以上置き、港1を接続する（接続 2→3、-10→-5）。外周を 8→12 枚以上、0,4 でスキルタイル1枚。
3. 手番を9回以上打つ（J2 で手札+1）。パスで工業点+6。

## 手段
- マーゴット（22G・ダイヤ1）で研究所駒2個を代金なしで鉱山（4,12・4,14）に置く（灰の歩）。
- Q（鉄5）で 14・15・16、16 の鉱業ボーナスでアイリーンが 17（灰2歩）。右端はダイヤ1。
- K8（8G）→ L1:A（4G・麦6）か A の2人目でタイル3枚、残りは fa1（手札1枚＋基礎資源3）。上辺 0,8→0,6→0,4→0,2、次に海 6,6→6,4。
- 代わり：Q を取られたら F（鉄3）と L1:F。K8 は K。J2 は J。

## 優先（打つ順）
J2（1スペース）→ マーゴット → Q → K8 → L1:A → fa1 → パス。

## 結果
1. 達成：研究所駒4個、工業17歩（アイコン6）、機関車駒を出した。灰の右端に最初に着いた（オートメーション化4枚）。
2. 達成：タイル8枚、港3/4（-5）、外周14で1位。スキル6と4（家2個目）でパス+13点。
3. 達成：9手番。G で地形・建物駒の繁栄を1歩ずつ。計105点。港4は麦不足で残した。
