# P0（エリ・マカロン）第5ラウンドの目標

## 目標
1. 港4を接続する（-5→+10、パス12点）。外周を 14→17 枚にして1位（15点）を守る。
2. 繁栄トラックを2本右端にする：地形タイル（2→5）と道駒（0→5）。ダイヤ2は特殊地形6（1,9）の裏返しで得る。
3. 機関車駒を8歩にする（アイコン8、スキル6を10点）。計200点以上。

## 手段
- A（麦6）で 6,2・6,0（繁栄1歩＝道駒）・3,9（林業ボーナス：G4・資源2・タイル1枚→1,9 に特殊地形6）。
- ベネディクト（12G）で道駒 2,12:w・1,11:sw・1,11:w（1,9 を裏返しダイヤ2）。
- Q（鉄5）で機関車3＝スキル1（オレンジ3歩で地形タイルを右端）。
- D（木6）で 0,10:sw・0,10:w（森2枚＝緑2歩）、クライド（18G）で道駒を右端。
- F（鉄3）で機関車5＝タイル2枚（1,11 工業1歩・0,14）、L1:F で8歩。
- 代わり：1人目を取られたら手札2枚。

## 優先（打つ順）
A → ベネディクト → Q → D → クライド → F → L1:F → パス。

## 結果

2. 達成：地形タイル（25点）と道駒（17点、最初）を右端にした。緑の歩は森4枚の裏返し。
