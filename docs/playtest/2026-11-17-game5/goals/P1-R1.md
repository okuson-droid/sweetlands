# P1 第1ラウンドの目標（カルメン・B4面・支援 列3）

## 目標
1. スキル4を取り、産業列を3列とも1枚にする（パス時 +6勝利点）。ダイヤは4以上を残す。
2. 地形タイル5枚・道駒5個を置き、麦畑を4枚以上裏返して麦の収入値を+3以上にする。
3. 食料トラック2歩・工業トラック2歩（それぞれ「地形タイル1枚と道駒1個」を得る）。

## 手段
- 1：エリアE でビル駒2個を首都（6,8・6,10）に置く（ダイヤ2＋スキルタイル）。グレン（11G）をプレイしてダイヤ1で農業列へ。
- 2：エリアA（麦6）で 5,7・5,9・4,8。道駒はグレンの2個と 4,8 のアイコン、F・B のボーナスで中央の麦畑を北へ。
- 3：F（鉄3）、エドガー（6G、麦+3）の後に B（麦4）。B が埋まれば K8（8ゴールド）に替える。

## 優先
E → A → F → エドガー → B → グレン。手札はフランシスかキャロラインを1枚持ち越す。

## 結果
- 目標1：達成。スキル4と3列1枚ずつで、パス時 +6勝利点。ダイヤ4。
- 目標2：達成。地形タイル5枚・道駒4個（1個不足）、麦畑5枚を裏返し麦の収入値 6（グレンの+1を含む）。
- 目標3：工業2歩は達成、食料は0歩。B の1人目を P2 に先取りされ、手札が足りず fa1 のタイル1枚に替えた。
