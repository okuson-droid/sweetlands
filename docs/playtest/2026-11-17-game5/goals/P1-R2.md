# P1 第2ラウンドの目標（カルメン・B4面・支援 列7）
## 目標
1. マイルストーン 1a（麦畑＋海10枚、いま5）を取る（+10）。地形タイル6枚以上。
2. カードを2枚プレイし（パス時+2）、鉱業列に1枚を無料でオートメーション化（計4枚）。
3. 農業・林業の産業ボーナスを各1回、食料トラック2歩。
## 手段
- 1：A（麦6）で麦畑3枚、ジェイコブで海と麦畑。10枚で fa4。
- 2：ジェイコブとリタ。ゴールドは K8・K。取られたら麦を fa5、リタをリーラに。
- 3：2,8 の農業ボーナス。B（麦4）の道駒で裏返す。B を取られたら2人目。
## 優先
J2 → K8 → A → ジェイコブ＋fa4 → リタ → B → K。麦畑の裏返しはオレンジの繁栄へ。

## 結果
- 目標1：1a は P2 に先取りされたが、キャロラインでショートケーキ4個にして 4b を取った（+10）。地形タイル5枚（特殊5：G+5・収入+7）。
- 目標2：カード2枚（レディ・キャロライン）、パス時+12。オートメーション化は未達（4b と道駒を優先しゴールド不足）。
- 目標3：農業ボーナス1回・食料2歩は達成、林業は0回。道駒4個で麦畑3枚と特殊を裏返した。
