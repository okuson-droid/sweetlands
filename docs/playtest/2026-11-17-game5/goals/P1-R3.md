# P1 第3ラウンドの目標（カルメン・B4面・支援 列2）
## 目標
1. 港を2つ接続する（港2・港3。失点 -40→-10）。
2. 食料5、建物駒4個（テント1・家1）、ラビット駒1個。
3. カード3枚プレイ、リタを鉱業列へ（計4枚）、鉱山2枚で港4へあと1枚。
## 手段
- 1：A（麦6）で 0,10（林業ボーナス）・1,11・1,13。取られたら L1:A。
- 2：N（麦7、不足は fa3）→ E（木材はヴィクター）。テントのタイルを 0,8 に置きラビット駒。N が無理なら B。
- 3：ジョスリンで手札2枚を3枚に替える。ゴールド不足なら K8。
## 優先
A → ジョスリン → ヴィクター → N → E → リタ。

## 結果
- 目標1：港3つ接続（港2・3は A、港4はリタの鉱山2枚＋ウェスの海）。失点 -40→-5。
- 目標2：食料4（麦不足で B に替えた）・ラビット駒1個は達成。建物駒は追加0個（E・P の1人目を先取りされ手札2枚が要った）。
- 目標3：カード4枚プレイ、リタを鉱業列へ（計4枚）、鉱山3枚。パス時+6。
