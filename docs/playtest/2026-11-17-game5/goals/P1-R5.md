# P1 第5ラウンドの目標（カルメン・B4面・支援 列2）
## 目標
1. ラビット駒を5個にし、繁栄「クッキーラビット駒」を右端へ（1個7点＋7勝利点）。スキル11で1個3点。
2. 建物駒3個（ショップ林業・農業、テント3個目）で産業ボーナス2回・キューブ+3、ワンダー2個目でスキルタイル。
3. 地形タイル4枚（1,7・1,5・0,4・0,6）で 0,4 のスキルタイル（スキル3）と外周12枚（中立と同数）。最終得点 250 以上、300 を狙う。
## 手段
- 1：N（麦7、食料8）→ O（麦9）→ クインシー → マービン＋C。オレンジは麦畑の建物駒3個、1,7 と 0,8 の裏返し、右端はダイヤ1。
- 2：最初の手で P の1人目（木材4を fa3 で買う）。取られたら E。
- 3：A（麦6）。取られたら L1:A か2人目。道駒は林業ボーナスを 1,9:w、クインシーを 0,8:sw。
## 優先
P → A か N → O → クインシー → C。手札は fa2 か H で足す。

## 結果
- 目標1：ラビット駒6個（1個多い）、右端に最初に着いた（+7）。繁栄42点＋スキル11で15点。
- 目標2：達成。建物駒3個、産業ボーナス3回、スキル11。P の1人目は最初の手で取った。
- 目標3：タイル4枚（1,7・1,5・0,4・0,14）。A は先取りされ B（食料9の2枚）に替えた。最終得点 244（1位）、300 には届かなかった。
