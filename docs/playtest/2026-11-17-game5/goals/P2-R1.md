# P2 第1ラウンドの目標（コーラル・ライラ、地図 B3、支援 列6）

## 目標
1. 建物駒を2個（家＋ビル）首都に置き、麦・鉄の収入値を各+1以上、ダイヤ+2を得る。
2. 地形タイルを3枚以上置き、うち2枚（5,7・5,9）を道駒 5,7:e で即裏返す。食料トラックを2歩にする。
3. 市民カードを2枚プレイ（ピーター・パヴロバ、ヴァニラ・ヴォルテックス）し、麦の収入値+1・ゴールドの収入値+2を得る。手番を増やすため J で2枚引く。

## 手段
- 1：area:E（木材4・鉄6）。3人目になっても手札2〜3枚で打つ。取れなければ L1:E。
- 2：area:A（麦6）で 5,7・5,9・6,6。食料は area:B（麦4、ピーターの麦3で賄う）。食料2のボーナス（地形タイル1枚＋道駒1個）も取る。
- 3：ゴールド18のうち14を使う。J が取られたら J2。捨てる手札はペニー・ローラ・モニカの順である。

## 優先（打つ順）
1. area:J（1スペース、スタートプレイヤーの利で最初に取る）
2. area:E（建物駒の1人目のスペース）
3. カード2枚 → area:A → area:B。余れば J2・H・D を見る。

## 結果
- 目標1：達成。家＋ビルを首都に置き、収入値は麦+2（首都の効果を含む）・木材+1・鉄+1、ダイヤ+2。
- 目標2：達成。地形タイル4枚（5,7・5,9・6,6 を裏返し、6,4 は表）、食料2歩、道駒3個。A の1人目は P1 に取られ L1:A（4ゴールド）で代えた。
- 目標3：達成。カード2枚をプレイし2枚ともオートメーション化、J で2枚引いた。収入値は G16・麦5・木材2・鉄1。
