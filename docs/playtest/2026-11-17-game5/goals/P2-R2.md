# P2 第2ラウンドの目標

## 目標
1. 港を1つ以上接続（港4：6,2・6,0）し、地形タイルを計8枚以上にする（海2枚を含む）。
2. 建物駒を計4個（テント＋研究所を足す）にする。
3. 手番を6回以上打つ（J か J2 で2枚引く）。灰の繁栄を2歩（オートメーション化の本）。

## 手段
- 1：area:A（麦6）で 6,2・6,0（pr）ともう1枚。海はベッカ（11G、2枚：4,10・3,9）。A の1人目が取られたら2人目（手札2枚）。
- 2：area:E（木5・鉄4）。置き場は 5,7・5,9・6,6。テントの地形タイル1枚も道筋に使う。取れなければ P か L1:E。
- 3：収入は灰2歩。J が取られたら J2、両方なければ H。余る手札は fa7h で資源にする。

## 優先（打つ順）
1. area:J（1スペース）
2. area:E の1人目 → area:A
3. ベッカ → 残りで F か B（鉄・麦が残れば）

## 結果
- 目標1：達成。港4を接続（1/4）、地形タイル13枚（海4・麦畑6）。マイルストーン 1a を獲得（+10）。
- 目標2：達成。テント＋家で建物駒4個、都市1。スキル4を取り、ベッカを鉱業列に入れてパス時+6。
- 目標3：手番は6回（J・E・A・ベッカ・サリー・パス）。灰は工業点2歩（鉄の収入+1）と 6,0 の1歩。K は先取りされ fa7h 2枚で代えた。
