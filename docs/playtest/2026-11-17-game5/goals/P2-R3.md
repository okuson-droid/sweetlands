# P2 第3ラウンドの目標

## 目標
1. 港を3つ接続にする（港2：0,8、港3：1,11→1,13）。外周の地形タイルを+2枚以上。
2. 建物駒を計6個（テント2個目＋ビル2個目）にし、農業・鉱業の列の上限を2にする。工業トラックを3歩以上（馬車2歩のボーナス：地形タイル1枚＋道駒1個）。
3. オートメーション化を計4枚以上（セスを農業列へ）にし、手番を6回以上打つ。

## 手段
- 1・2：area:A（麦6）で 6,12（in）・1,11（in）・0,8。工業2歩のボーナスで 1,13 と道駒 6,10:e（6,12 を裏返して置き場を2か所にする）。A が3人目なら L1:A。
- 2：area:E（木6・鉄6）。足りない木1・鉄3は fa7h 2枚で補う。置き場は 5,9 と 6,12。取れなければ P か L1:E。
- 3：収入は緑2歩（建物駒の本、木材の収入+1）。J で2枚引く。E の後にセス（9G）をプレイしダイヤ1で農業列へ。残りのダイヤは鉱業か林業のカードに使う。

## 優先（打つ順）
1. area:J（1スペース）
2. area:A の1人目 → area:E
3. セス → 手札と資源が残れば I（ダイヤ）・F・カード。

## 結果
- 1：港2/4（0,10 で港2）。1,13 は後回し、外周+2。
- 2：建物駒6個（テント＋家、ダイヤ2）。工業2歩。鉱業の上限は1のまま。
- 3：自動化4枚（オスカー）、手番7回。ラビット1個で木・鉄の収入+2。
