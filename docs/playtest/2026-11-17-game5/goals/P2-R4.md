# P2 第4ラウンドの目標

## 目標
1. 港を4つ接続にする（2/4→4/4、パス時 列5で12点）。外周の地形タイルを9枚以上。
2. 時計塔駒を置く（ワンダー1個＋馬車4歩）。パス時に時計塔で6点以上。
3. ユリアを林業列へ自動化（計5枚以上）。ビル2個目で鉱業の上限を2にする。建物駒を計8個以上。

## 手段
- 1：area:A（麦6）で 1,5・1,3（tl）・0,2・1,13。取られたら fa1。
- 2：収入の1歩は建物駒の本、能力の2歩はラビットの本（食料5→ワンダー）。工業はユリアのビル＋ area:F。
- 3：ユリア（18G＋資源5）。残りのダイヤは鉱業のカードへ。余りでテント3個目（2個目のワンダー）。

## 優先
1. area:A の1人目 2. ユリア → F → fa8 3. E か C → パス

## 結果
- 1：達成。港4/4（パス時12点）、外周10枚。0,4 でスキル1（地形タイルの本3歩）。
- 2：達成。時計塔を 4,10 に置きパス時10点。テント3個目のワンダーでスキル3（灰3歩）。
- 3：達成。ユリア・カスタードを自動化（計6枚）、スキル4で12点、建物駒9個。K8 は P0 に先取りされ fa5 で補った。
