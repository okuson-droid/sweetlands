# P2 第5ラウンドの目標（最終。いま135点・P1 160）

## 目標
1. 繁栄の右端を2本取る：地形タイル（4/5→右端、約+14点）とオートメーション化したカード（4/5→右端、+6点以上）。ダイヤ2はタビサ（16G）で得る。

- 3：安いカードをプレイ、余る手札は fa7h。
