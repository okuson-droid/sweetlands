# P0 の知見（エリ・マカロン、地図 A、207点・3位。P1 244・P2 229）

## 内訳
勝利点44、繁栄110（工業点48・地形タイル25・道駒17・オートメーション16・建物駒4・ラビット0）、都市点12、港10、マイルストーン10、外周15、金6。第5ラウンドだけで +102。

## 効いた判断
- 工業を17歩まで進め、工業点の繁栄を右端にした（48点。パスごとの工業点が2倍で効く）。
- 特殊地形6（ダイヤ2）を道駒で裏返し、右端2本のダイヤを1手で得た。
- 道駒で森・麦畑を裏返すと繁栄の歩になる。道駒3個＋タイル2枚で道駒の繁栄を 1→5 にした。

## 誤った判断
- 食料0・ラビット0のまま終えた。1位はラビットの繁栄42点とパス時の点で伸びた。
- 第4ラウンドまで道駒が鉱山の側だけで、麦畑・森を裏返さなかった。置き場も繁栄の歩も第5ラウンドまで無かった。
- 産業列が 1/2/1 のままで、スキル4は毎回6点、オートメーション化は4枚（最終得点計算0点）。テント・ビルの2個目を早く置くべきだった。
- 港の接続を第5ラウンドに残し、パス時の港点を1回しか取れなかった。

## 分かりにくかったこと
- 裏返しの選択は choice:1 の後に pros:<番号> と2段になる。
- 辺の ID は出力で隣のヘクスの名に書き換わる（2,12:w → 2,10:e）。道駒がどの頂点でつながるかは下見でしか分からない。
- 第5ラウンドは手札を0枚にでき、余った手札は K・K8 で金にするのが fa1 より得だった。
