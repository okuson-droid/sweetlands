# ラウンドの打ち手の追加の務め：ラウンドの目標

## ラウンドの初め（最初の手を打つ前）
`.play/goals/P<席>-R<ラウンド>.md`（1.5KB＝日本語で約500字以内、である調）に、このラウンドの目標を書く。
- 目標（3つまで）：何を達成するか。数字で書く（例：港を2つ接続、ラビット駒を2個、勝利点+15）。
- 手段：それぞれをどのエリア・カード・フリーアクションで達成するか。先に取られたときの代わり。
- 優先：取り合いになるもの（1スペースのエリア・1人目のスペース・マイルストーン・右端）から打つ順。

## ラウンドの終わり（ノートを書いた後）
同じファイルの末尾に「結果」を足す（3行以内）：各目標を達成したか（数字）、達成できなかったものの理由（先取り・資源不足など）。

## 注意
- eff:・bundle: の番号は1つ解決するたびに詰まる。順番を気にしないなら order:auto を並べる。
- パス時の支援タイル「プレイしたカード1枚につき1勝利点」は、これまでにプレイしたカードの累計（オートメーション化したカードを含む）で数える（エンジンの実装の事実）。
- 他の席のノート・目標は読まない。
