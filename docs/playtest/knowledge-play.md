# 打ち手向けの知見（要約）

2026-11-16 の3局（3人戦。最高点 210→287→311）から。目標は300点。局面で確かめて使うこと。

## 繁栄トラック：歩より「数える対象の数」
- 点＝位置の区間の率×対象の数。率は `ref --only tracks`。1歩目が重く、右端が最も高い。
- 右端に乗せる2〜3本を第2ラウンドまでに決め、それぞれにダイヤ1を残す。右端のボーナスは最初の1人だけ。他席が迫る本はスキル1〜3（同色3歩）で先に着く（3局目の1位）。
- 2・3局目は工業点のトラックがほぼ0歩、建物駒のトラックも1歩の席が多い。手つかずの本の1歩目を早く踏む。

## ラビット駒（2局目で最も伸びた）
- n個目は食料 3+n 以上で、建物駒のあるヘクス（1ヘクス1個）に置く。食料（B・N）を第4ラウンドまでに9以上へ。
- 右端なら1個7点、スキル11なら置くたび3点。テント5個目は終局でラビット駒×2点。
- 食料が足りないままラビットのアイコンを踏むと何も得ない。

## 産業列とスキル4
- 列の上限は 1＋（同じ列の建物駒を2個取った）＋（4個取った）。テント=農業・家=林業・ビル=鉱業。
- スキル4（パス時、3列の最小が1/2/3枚で6/12/24点）は、3列2枚で毎パス12点。種類をそろえて建てる。

## 第5ラウンドの前の点検（2局目、3席とも点の多くを第5ラウンドで取った）
- 建物駒の置き場（首都か、裏返したタイルの空き）が足りるか（`show --only self` の点検）。カードの代金なしの建物駒は、列の上限が増える段か高い段に当てる。
- 建物駒のエリアの前に代金をそろえる。エリアの効果の途中はフリーアクションを挟めない。
- 港は4つとも首都までタイルでつながるか（接続0〜4で -40/-20/-10/-5/+10）。足りない枚数を数える。
- 道駒は辺で接するタイルだけを裏返す。遠いタイルには2個要る。

## 手番の数と先取り
- 手番の数は手札の数で決まる。J・J2・追加ドローエリア・ディスクを序盤に取る。余る手札は fa7h（手札1枚→資源2）。
- 2人目以降のスペースは手札2〜3枚。1スペースのエリアと使いたいエリアの1人目は最初の手で取る。スキル12・時計塔など回数で効くものは早く。
- マイルストーンは3つ取られると締め切り。1局目は第2ラウンドで締め切られた。

## 終局の計算
- 最終得点計算タイルは中立の値も順位に入り、同点の1位は両方15点。`score` の末尾の各席の値を毎ラウンド見る（1枚差で15点→7点になった席が2局で2回）。
