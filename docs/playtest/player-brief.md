# 打ち手への指示

スイーツランドの1席を打ち、自分の最終得点を最大にする。

- 席 P<席>、作業ディレクトリ <作業ディレクトリ>。`play` は `node <リポジトリ>/dist-play/cli.js`（作業ディレクトリで呼ぶ）
- 記録 `.play/game.json`（共有）、ノート `.play/notes/P<席>.md`。いまのラウンド R は起動の指示にある

## 手順
1. `play resume --seat <席>` を1回呼ぶ。ノートと `knowledge-play.md` を読む。第1ラウンドは `play ref` を、作り直した打ち手は `play ref --only rules,ids` を最初に1回読む（地図を選ぶ前は `--only maps`）。
2. `play wait --seat <席> --round R` で番を待つ。「まだ番ではない」なら同じものをもう一度呼ぶ。
3. 番が来たら選択肢を ID か番号で選ぶ。1手番（行動から endTurn まで）が決まっていれば、1回の `play move <選択>... --seat <席> --then-wait --round R` にまとめる。番号はいま出ている段にだけ使い、2つ目からは ID で書く。選べない指定は記録を変えず、その段の選択肢が出る。
4. 迷う手は `play move --dry-run <選択>... --seat <席>` で下見する。
5. 「ラウンド R は終わった」でノート、「ゲーム終了」で知見を書いて終える。

## 見るもの
`play show --seat <席> --only <欄>`（self・map・hand など）、`play show --player <N>`（他の席）、`play ref --only <欄>`、`play ref --card <ID か名前>`、`play score`。

## 要点（ルールの事実）
- 港が首都とタイルでつながらないと大きく失点（接続0〜4：-40/-20/-10/-5/+10）。
- タイルは道駒が接すると裏返り効果が出る。建物駒は首都か裏返したタイルに置く。3種類以上つながると都市。
- 第1〜4ラウンドは手札を0枚にできない。ディスクはラウンド末に失う。手札は1枚だけ持ち越す。
- 残ったゴールドは5につき1点。基礎資源は第5ラウンドのパスでゴールドになる。
- マイルストーンは fa4 で取る。建物駒の効果は置き終えた後に来て、順を bundle で選ぶ。

## 守ること
- 番待ちは `wait` を1回ずつ呼ぶ。シェルのループや sleep で待たない（道具の上限の約120秒で止まる）。
- リポジトリのファイルは読まない・変えない。記録を直接書き換えない。
- 他の席のノートを読まない。他の席の手札を推測しない。
- 一時ファイルは `.play/tmp-P<席>-*` だけ。

## ノート（ラウンドの終わりに上書き、1.5KB＝約500字以内）
方針、次のラウンドの最初の手、狙い（取られうるエリア・マイルストーン）。局面の写しは書かない。

## 知見（終局後、2KB 以内、`.play/insights/P<席>.md`）
得点と内訳、効いた判断・誤った判断（各3つまで）、分かりにくかったこと、コマンドへの要望。
