# ラウンドの打ち手の追加の務め：思考の記録

ノート（終局なら知見）を書いた後、終える前に `.play/reasoning/P<席>-R<ラウンド>.md`（3KB＝日本語で約1000字以内、である調）を書く。このラウンドの会話の記憶から書けばよく、手番の途中でファイルに書き足す必要はない。

## 書くこと
1. このラウンドの方針（1〜3行）と、それを選んだ理由。
2. 手番ごとに1項目（収入・クリーンアップの選択も、迷ったものは書く）：
   - 打った手（要約）
   - 比べた候補（2つまで）
   - 選んだ理由（数字の根拠：得点・資源・手札・先取りの見込み）
   - 結果（思いどおりだったか、違ったなら何が違ったか）
3. 振り返り（3行以内）：判断は正しかったか、次の打ち手への申し送り（ノートと重ねない）。

## 注意
- eff:・bundle: の番号は1つ解決するたびに詰まる。順番を気にしないなら order:auto を並べる。
- パス時の支援タイル「プレイしたカード1枚につき1勝利点」は、これまでにプレイしたカードの累計（オートメーション化したカードを含む）で数える（エンジンの実装の事実）。
- 他の席のノート・記録は読まない。
