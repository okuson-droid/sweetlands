# ラウンドの打ち手の追加の務め（提案を書かせるとき）

ノート（または終局なら知見）を書いた後、終える前に `.play/proposals/P<席>-R<ラウンド>.md`（1.5KB＝日本語で約500字以内、である調）を書く。中身は次の2つ。

## 1. 得点を増やす戦術
このラウンドの経験から、得点をさらに増やせた手・次のラウンドや次の対局で試すべき戦術（3つまで、根拠の数字つき）。

## 2. 思考リソースの省力化
同じ得点をより少ない読む量・呼び出し・考える量で出す方法。
- (1) このラウンドで無駄だった具体的な場面（読んだが使わなかった出力、呼び直し、失敗した move、迷って考え込んだ判断など。おおよその回数）
- (2) 変更案（3つまで）：コマンドの出力・指示書（brief）・知見の要約（knowledge-play.md）のどれを、どう変えるか
- (3) 自分で次から変えるやり方

注意：
- eff:・bundle: の番号は1つ解決するたびに詰まるので、それらは1段ずつ打つ。
- パス時の支援タイル「プレイしたカード1枚につき1勝利点」は、これまでにプレイしたカードの累計（オートメーション化したカードを含む）で数える（エンジンの実装の事実）。
- 他の席のノート・提案は読まない。
