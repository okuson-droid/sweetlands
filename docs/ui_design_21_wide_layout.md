準拠：`ui_design.md`（第3版）、`decisions.md`
状態：ユーザー承認済み（2026-10-11）。画像によるレイアウト案（案A → 案A改-1 → 案A改-3）をユーザーが選び、本体への反映を指示した。
位置づけ：この追補は `ui_design.md` §4.1 の PC 配置を置き換える。§20 の共通サプライの行と、§4.1 の「上下の境目をドラッグで動かす」「共通サプライは常に見える位置に置く」を改める。スマートフォン横持ち（§4.2）は変更しない。

## 21.1 配置（1280×720 を基準）

```
┌──────────────────────────────────────────────────────────────┐
│ 札（ラウンド・手番順・スタート）                         [みんな][ログ][設定] │
│ 相手の帯（クリックで右半分をその人の場に切り替える）                         │
│ 帯：いますべきこと                                                  ［ボタン］ │
├───────────────────────────────┬──────────────────────────────┤
│ 共有ボード（左半分）                 │ 個人ボード（右半分）                       │
│ ┌繁栄トラック［拡大］┬アクションエリア┐ │ ┌工業発展ボード［拡大］──┬キャラボード［拡大］┐ │
│ │                 │               │ │ │                       │（個人ボード）     │ │
```

- 左右は半分ずつ。左半分は卓の中央（共有ボード）と手札、右半分は自分の場。
- メインボードは3列を「繁栄トラック｜アクションエリア」と下段のボタン列に組み替え、76% で表示する。キャラボードは 116% で表示する。
- 右半分は、上に工業発展ボード、下に地図ボード、右の列にキャラボードを置く（ユーザー指示：工業ボードとマップの上下を入れ替える）。

## 21.2 クリックで展開するもの（ユーザー指示）

常時は出さず、ボタンを押すと中身が浮いて開く。中身は盤面の上に重なり、配置を押し出さない。

- ラウンド支援ボード、フリーアクション、スキルタイル（基本と上級をまとめて）：メインボード下段のボタン。
- 特殊地形タイル：共通サプライの「特殊」ボタン。
- プレイしたカード：共通サプライの「プレイ済」ボタン。手札と同じカードの表面で並べる。

設計原則 2・3（合法な対象が光る、画面はルールを持たない）を守るため、次の規則で開く。

- 操作の対象になったときは、閉じていても自動で開く：ラウンド支援駒を置くとき、特殊地形タイルを選ぶとき、カードをプレイする（手元が置き先になる）とき、プレイしたカードをオートメーション化するとき、スキルタイルを獲得するとき。
- フリーアクションは手番中ほぼ常に使えるため、自動では開かない（開くと盤面を塞ぎ続けるため）。かわりに、使える手が中にあるボタンには印（●）を付ける。ディスクや手札の置き先になったときだけ自動で開く。
- スキルタイルも、使える手があるあいだは印（●）を付ける。

## 21.3 表示を省くもの（ユーザー指示）

- 地形タイル4種の残り枚数は表示しない（情報としての価値がないため）。§20 の「共通サプライ：地形タイル4種の残り」を削る。
- 通常の地形タイル4種と道駒の山は、置ける選択待ちのときだけ共通サプライに出す。アクションディスク・特殊地形タイル・捨て札置き場・市民デッキは常に出す。

## 21.4 手札（ユーザー指示：重ねてよい、カーソルを合わせたときに見えればよい）

- 1列に重ねて並べる。1枚 177×139px（従来の約1.7倍）。最後の1枚は全体を見せ、残りは左端の帯（約55px）を残して重なる。
- カーソルを合わせたカードは、手札の上の決まった位置に「カードの表面（約2倍）＋カードの文章（即時能力・オートメーション能力・タグ）」の覗き窓で見せる。手札のカードそのものは動かさない。
  - 理由：合わせたカードを前に出す方式では、前に出たカードが右隣の2枚を覆い、右へなぞっても次のカードへ移れなかった。
- 手札にカーソルがあるあいだは、§13 の拡大表示の小窓を出さない（覗き窓に同じ内容があり、重なって読めなくなるため）。

## 21.5 拡大表示（ユーザー指示）

- 繁栄トラック・地図ボード・キャラボード・工業発展ボードの右上に「拡大」ボタンを置く。
- 繁栄トラックは左半分（共有ボード側）の中だけを、ほかの3つは右半分（個人ボード側）の中だけを覆って拡大する。反対側へははみ出さない。「閉じる」で戻る。
- 拡大中も操作の対象は光り、拡大した盤面の上で操作できる。

## 21.6 受け入れ基準（§16 への追加）

- 合法手の対象が、見えている要素か、●印の付いた展開ボタンの中にあること（`e2e/autoplay.mjs` の unreachable 検査。0件であること）。
- 手札のすべてのカードについて、左から右へなぞったとき覗き窓が正しいカードに切り替わり、覗き窓の全体が見えること。
- 拡大表示が反対側の半分にはみ出さないこと。

## 21.7 改訂（2026-10-11、ユーザー指摘による）

- 特殊地形タイル：鉱山の灰色と見分けにくかったため、濃いピンクと白の斜めの縞に変え、アイコンでは中央に白い星を付けた（色だけに頼らない）。地図上の特殊地形ヘクスも同じ縞。
- プレイしたカード：共通サプライの列から外し、キャラボードの下の帯に置いた。帯をクリックすると一覧を開く。手札のカードを持ち上げているあいだは帯そのものが置き先（「ここに置いてプレイ」）になり、置くとプレイする。プレイしたカードをオートメーション化する場面では一覧を自動で開く。
- キャラボードの表示倍率を 1.16 から 1.12 にした。下に帯が入っても、14人すべてのキャラボードがスクロールなしで収まる（全員を実測）。
- カードの高さ：効果のアイコンが切れることがあったため、全207枚の表面を高さ自由で描いて実測した（最大 97px）。カードの高さを 76px から 100px にした（手札・プレイしたカード・候補の小窓など、カードを描くところすべて）。
- 手札のカードを持ち上げているあいだは覗き窓を出さない（置き先のフリーアクション欄などを覆わないため）。
- 準備でキャラクターを選ぶとき、各キャラクターの「キャラボードを見る」で、建物駒置き場・産業列・時計塔の条件などを含むキャラボードを確認できるようにした。確認中に「このキャラクターを選ぶ」で選べる。
