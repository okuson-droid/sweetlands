# 人の基準プレイの案内（sim/PLAN.md §5.5・§6.7）

強さの関門のために、AI と同じ条件で1人プレイを5局遊び、その記録を書き出してもらう。記録（初期シードと手の列）はシミュレーターで再生し、初期状態が AI の対局と同じこと、マイルストーンを取っていないことを確かめてから、AI と同じ集計で得点を出す。

## 遊ぶ局

シード 1〜5 の5局（測定帯の先頭）。各シードを1回ずつ遊ぶ。

## 開き方

アプリの URL の末尾に `?auto=1&players=1&seed=N` を付けて開く（N はシードの番号）。例：

- `https://okuson-droid.github.io/sweetlands/?auto=1&players=1&seed=1`
- 同様に `seed=2` 〜 `seed=5`

`v=1` は付けない（ヴァリアントはすべてなしにする）。

## 遊び方（条件）

1. キャラクターは「エリ・マカロン」を選ぶ。
2. 地図ボードは「A面」を選ぶ（どのボードの A面でもよい）。
3. ラウンド支援駒の初期位置は自由に選んでよい（AI も自分で選ぶ）。
4. マイルストーンは取らない（フリーアクションの「マイルストーンを獲得」を使わない）。取った記録は集計の対象外になる。
5. 最終得点計算タイルは画面に出るが、集計では数えない（AI も同じ）。気にせず遊んでよい。
6. それ以外は通常どおり遊ぶ。自分の最終得点を最大にすることを目指す。取り消しは使ってよい（記録には取り消したあとの手の列だけが残る）。

## 記録の書き出し

- 終局後の得点画面の「記録を書き出す」を押すと、`sweetlands_seed1_….json` のようなファイルが保存される。
- 途中で中断したいときは、設定（上の帯の「設定」）の「記録を書き出す（JSON）」でも書き出せる（途中の記録は集計に使えないので、続きを遊んで最後に書き出し直す）。
- ローカル対局は同じブラウザに1局分だけ自動保存される。ロビーの「続きから遊ぶ」で再開できるが、新しい局を始めると上書きされる。

「記録を書き出す」ボタンは main に入っており（PR #4）、公開中のアプリで使える。

## 記録の渡し方

5つのファイルを `sim/reports/pilot/human/` に置く（または Cowork に渡す）。ファイル名は変えてよい。

## 集計（Claude Code が行う）

```
node sim/build.mjs main   # sim/ で実行
node sim/dist/main.cjs human --records reports/pilot/human/a.json,reports/pilot/human/b.json,... --out reports/pilot/human.csv
```

各記録について次を確かめ、問題があれば理由を出す。

- 設定が1人・ヴァリアントなしであること。
- 市民デッキの並び・ラウンド支援タイルの配置・スタートプレイヤーが、AI の同じシードの対局と一致すること。
- キャラクターがエリ・マカロン、地図が A面であること。
- マイルストーンを取っていないこと、最後まで遊んでいること。

得点は、マイルストーンと最終得点計算タイルの行を除いた最終得点で、AI と同じ集計である。
