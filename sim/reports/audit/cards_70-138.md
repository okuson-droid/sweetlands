# 市民カード監査（70〜138枚目：p05-r2c5 〜 p10-r1c3、69枚）

対象：`cards_side_by_side.md` の 711〜1414 行目。文面（main_text・auto_text）と、アイコン表記をパーサー（`src/game/cards.ts`）が変換した構造（Eff）が同じ意味かを1枚ずつ見た。

判定の基準
- 一致：文面と構造が同じ意味である。
- 疑い：構造が文面と違う読みになっている。
- 文面側の問題：文面（データ）がアイコンと食い違う、または「要確認」「メモ」で未確定のままである。

読みの前提（`rules_excerpt.md` §12.5・§13.2、`queries.ts`）
- `=>` は each:false（満たしていれば1回だけ）、`=>*` は each:true（floor(数 / n) 回）。複数の条件は各項の回数の最小値。
- 塗りつぶしの地形アイコン（hexW など）は表裏を問わず数える（backOnly:false）。「裏」付きのときだけ裏向きのみ。
- playedAgr／playedMin はオールマイティ産業のカードも1枚に数える（`playedCount`）。
- `[G]` など収入アイコンは、得る側では収入+n、支払う側では収入−n、条件側では収入値を数える。
- `IP2 =>* VP1` のように月桂樹の内側の数字は n に掛ける（`laurel`）。

### 文面側の問題（4件）

- p06-r2c5 ドクター・ドーナッツ：アイコン `4 Wd -> searchMacaron2` は `search tag:マカロン n:2`（デッキからマカロンタグのカードを2枚選んで手札に加える）に変換される。文面は「探して手札に加える（アイコン推定）」で枚数を書いておらず、メモにも「凡例Cの探索アイコンと判断したが正式トークンなし」とある。2枚という数の根拠を持ち主に確認し、文面に枚数を書くべきである。
- p06-r3c2 マーブル・マドレーヌ：同じ探索アイコンで `1 hand -> searchMacaron2`。文面に枚数がないことに加え、メモで「絵柄が不鮮明、ブラウニーの可能性もあり要確認」とある。探すタグ（マカロンかブラウニーか）と枚数の両方が未確定。
- p07-r3c3 バーナード・ブランマンジェ：効果の構造（食料2歩、ショートケーキ3個で1回だけ食料1歩、オート麦収入+1）は文面と一致する。要確認はコスト（17と推定）と英語名の前半で、`rules_excerpt.md` §14 にも残っている。
- p09-r2c3 ポリー・パヴロヴァ：文面「地図ボード上に建物駒を1個置き」、アイコン `placeBld`、構造 `building`（onTerrain なし）は互いに一致する。しかしメモは「台座が灰色の六角形なので placeBldM と判断（汎用の placeBld ではない）」と書いており、アイコン表記と食い違う。要確認（§14）のとおり持ち主に確認し、鉱山限定なら main_icons を `placeBldM` に直す必要がある（そのとき条件行の建物も同じ台座か確認する）。
