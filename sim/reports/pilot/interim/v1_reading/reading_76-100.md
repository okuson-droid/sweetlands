## 4. 評価関数・探索に足すべきもの

1. **ゴールドと基礎資源の重みを逆転させ、ラウンド途中の売却をやめさせる。** fa5 が 511 回、R1 に木材・鉄を全部売って建物を建てられなくなる局が 7 局ある。1 手番先読みでは「+1 ゴールド」が常に正で、資源を手元に残す価値が見えない。資源 1 に「次に打てる行動の期待得点」（少なくともゴールド 1 より大きい値）を与え、fa5 は最終ラウンドのパス直前だけ許すのが簡単である。fa3×5＋fa6 の往復（4 局）は 麦3 → 麦1 の純損失を選んでいるので、重みの不整合か同点時の選び方の不具合を先に直す。
2. **手札 1 枚に「残りラウンド数 × 1 行動の平均得点」の価値を置く。** fa7h 201 回・fa1 120 回・fa7d 15 回・「ここで終える」19 回はすべて、手札（＝行動回数）を資源 2 や 0 と交換している。seed89 のように E に手札 2 枚を払って何も置かない手が選ばれるのは、手札コストが評価上ほぼ 0 だからである。E／P で駒を置けないときは合法手から除くか、手札コストに負の値を付ける。
3. **収入値に残りラウンド数を掛け、ゴールドの終局価値を小さくする。** R3 頭の収入合計は 6〜12（人は 26）で、ゴールドは全局 100 超で死蔵、play は 25 局で 22 回、fa2 は 1 回。収入 +1 は「残りラウンド × 1 資源」なので、1 手番先読みでも係数を掛ければ R1〜R2 に E（incomeAny）や収入系カードを選ぶ。終局ゴールドの重みを 0 近くにすれば、ゴールドを fa2 やカードプレイに回す手が自然に浮上する。
4. **繁栄トラックを「位置 × 対応する駒の数」の積で評価する。** ラビット 0 でラビット軌道を進める局が 12、建物 3 で建物軌道 6（seed94）、工業点なしで工業点軌道 3 歩（77・89）がある。G とタイルのスキル「○色 3 歩」が個数を見ずにトラックを選ぶのは、評価がトラック位置の線形和だからである。積にすれば、駒 0 のトラックは 0 点となり、C／O（ラビット）や Q（工業）を打つ動機も生まれる。
5. **ラウンド末までの手の列を探索し、パスに未使用資源の負の価値を付ける。** 主行動は 1 ラウンド平均 4.7（人は 10.8）で、1〜2 手番でパスする局が 7 ラウンド分ある。1 手番先読みでは「手札を払って得る次の手」が負に見えてパスが最善になる。少なくともラウンド末までのビーム探索（幅 3〜5）にし、パス時に残る資源・手札・ダイヤを減点すれば、J → play、E → 時計塔（テント 2 個）、A → O（ラビット）のような 2〜3 手番の組み合わせが評価できる。時計塔 0 回・都市 0・C/D/N/O/Q/M 0 回は、いずれも複数手番の計画がないと得点にならない要素である。
