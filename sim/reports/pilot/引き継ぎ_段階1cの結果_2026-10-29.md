## 3. 決めたこと（Claude Code の判断。理由は §5G）

- J のような主行動の準備の手は、手番を終えて次の手番の主行動を孫にした。理由：J 自体がその手番の主行動なので、同じ手番の中に孫が作れなかった。
- 2手先の順位付けは、主行動の子に限った。理由：フリーアクション（fa7h・fa3・fa2）まで含めると、どの得点の手より上に来た。両替は前置の候補で扱うことになっている。
- 前置の両替の内訳は、計画の手の列に含めて、そのとおりに打つ。
- main の PR #16・#17（ジャスミン・エリの上方修正の変更）は取り込んでいない。理由：ジャスミン・セナの記録の再生が変わるおそれがあるため。

## 4. 次の判断の材料

- **残る原因は、順位付けの物差しのずれ。**

  - 段階1c では、準備の手にだけ先読みを付けたため、得点の手が落ちた。
- **次の候補（どちらも未実施）**
